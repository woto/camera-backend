# Política de Privacidade da VolleyCam

**Última atualização:** 5 de janeiro de 2026.

## 1. Visão geral
VolleyCam inclui o aplicativo Android e o site da VolleyCam em `volleycam.com`. O app grava jogos de vôlei usando um mecanismo de buffer estilo “dashcam”, e o site permite visualizar e gerenciar gravações. Os usuários entram em uma “sala” usando um código de 6 dígitos para associar os clipes a uma sessão de jogo.

## 2. Informações que coletamos

### 2.1. Dados de vídeo e áudio
- **O que coletamos:** o app acessa a câmera e o microfone do seu dispositivo para gravar vídeo e áudio de jogos de vôlei.
- **Como é usado:** o app mantém um buffer contínuo na memória. Somente quando ocorre um evento de “gatilho” (iniciado pelo usuário a partir de um telefone celular ou pelo site usando o código da sala), o segmento relevante (vídeo e áudio) é salvo permanentemente e enviado aos nossos servidores (`volleycam.com`).
- **Uso em segundo plano:** o app continua gravando com a tela desligada para preservar a bateria durante jogos longos (normalmente 3 horas).

### 2.2. Identificação da sala
- **O que coletamos:** um ID de sala de 6 dígitos criado livremente pelos usuários para a sessão de jogo.
- **Como é usado:** para associar clipes enviados a uma sessão de jogo específica e controlar o acesso no site.

### 2.3. Dados de uso do site
- **O que coletamos:** dados padrão de logs da web, como endereço IP, tipo de navegador e páginas acessadas. O site também usa cookies para manter você conectado, lembrar sua preferência de idioma e manter a sala atual selecionada.
- **Como é usado:** para operar o site, proteger o acesso às gravações e fornecer as páginas e recursos solicitados.

### 2.4. Identificador do dispositivo
- **O que coletamos:** um identificador técnico do dispositivo (UUID aleatório) armazenado no dispositivo.
- **Como é usado:** para gerar nomes de arquivos únicos e processar corretamente os envios no servidor.

## 3. Compartilhamento e transferência de dados
- **Envio para o servidor:** clipes gravados são enviados para nosso servidor seguro `volleycam.com`.
- **Criptografia:** toda a transferência de dados é criptografada usando protocolos padrão HTTPS/WSS.
- **Visibilidade pública:**
    - Clipes associados a um ID de sala são acessíveis a qualquer pessoa que possua esse código válido de 6 dígitos.
    - **Importante:** após um clipe ser “publicado” ou enviado, ele pode ficar publicamente acessível a qualquer usuário na internet que tenha o link correto ou o ID da sala via o site. Não use este serviço para gravar momentos privados ou sensíveis.

## 4. Retenção de dados
Os clipes enviados são armazenados indefinidamente até serem excluídos pelo usuário. Os usuários podem excluir clipes pelo site se souberem o ID da sala. Você também pode contatar o administrador do site para solicitar a exclusão. Em alguns casos, os clipes podem ser removidos a critério do administrador. As gravações em buffer na memória do dispositivo não são salvas se nenhum gatilho foi enviado.

## 5. Direitos e controle do usuário
- **Envio:** você controla quando o app está ativo e gravando.
- **Exclusão:** usuários com acesso ao ID da sala podem excluir clipes pelo site da VolleyCam. Você também pode solicitar a exclusão entrando em contato com o suporte.
