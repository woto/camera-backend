# Kebijakan Privasi VolleyCam

**Terakhir diperbarui:** 5 Januari 2026.

## 1. Ringkasan
VolleyCam mencakup aplikasi Android dan situs web VolleyCam di `volleycam.com`. Aplikasi merekam pertandingan bola voli dengan mekanisme buffer ala “dashcam”, dan situs web memungkinkan pengguna melihat serta mengelola rekaman. Pengguna bergabung ke “room” tertentu menggunakan kode 6 digit untuk mengaitkan klip dengan sesi pertandingan.

## 2. Informasi yang kami kumpulkan

### 2.1. Data video dan audio
- **Apa yang kami kumpulkan:** aplikasi mengakses Kamera dan Mikrofon perangkat Anda untuk merekam video dan audio pertandingan bola voli.
- **Bagaimana digunakan:** aplikasi terus mem‑buffer video di memori. Hanya saat terjadi peristiwa “pemicu” (dipicu oleh pengguna dari ponsel atau dari situs web menggunakan kode room), segmen yang relevan (video dan audio) disimpan secara permanen dan diunggah ke server kami (`volleycam.com`).
- **Penggunaan latar belakang:** aplikasi terus merekam saat layar mati untuk menghemat baterai selama pertandingan panjang (biasanya 3 jam).

### 2.2. Identifikasi room
- **Apa yang kami kumpulkan:** ID Room 6 digit yang dibuat bebas oleh pengguna untuk sesi permainan mereka.
- **Bagaimana digunakan:** untuk mengaitkan klip yang diunggah dengan sesi permainan tertentu dan mengontrol akses di situs web.

### 2.3. Data penggunaan situs web
- **Apa yang kami kumpulkan:** data log web standar seperti alamat IP, jenis browser, dan halaman yang diakses. Situs web juga menggunakan cookie untuk menjaga Anda tetap masuk, mengingat preferensi bahasa, dan mempertahankan pilihan room saat ini.
- **Bagaimana digunakan:** untuk mengoperasikan situs web, mengamankan akses ke rekaman, dan menyediakan halaman serta fitur yang diminta.

### 2.4. Identifikasi perangkat
- **Apa yang kami kumpulkan:** identifikasi teknis perangkat (UUID acak) yang disimpan di perangkat.
- **Bagaimana digunakan:** untuk membuat nama file unik dan memproses unggahan dengan benar di server.

## 3. Berbagi dan transfer data
- **Unggahan ke server:** klip yang direkam diunggah ke server aman kami `volleycam.com`.
- **Enkripsi:** seluruh transfer data dienkripsi menggunakan protokol standar HTTPS/WSS.
- **Visibilitas publik:**
    - Klip yang terkait dengan ID Room dapat diakses oleh siapa pun yang memiliki kode valid 6 digit tersebut.
    - **Penting:** setelah klip “dipublikasikan” atau diunggah, klip tersebut dapat diakses publik oleh siapa pun di internet yang memiliki tautan yang benar atau ID Room melalui situs web. Jangan gunakan layanan ini untuk merekam momen pribadi atau sensitif.

## 4. Retensi data
Klip yang diunggah disimpan tanpa batas waktu hingga dihapus oleh pengguna. Pengguna dapat menghapus klip melalui situs web jika mengetahui ID Room. Anda juga dapat menghubungi administrator situs untuk meminta penghapusan. Dalam beberapa kasus, klip dapat dihapus atas kebijaksanaan administrator. Rekaman buffer di memori perangkat tidak disimpan jika tidak ada pemicu yang dikirim.

## 5. Hak dan kontrol pengguna
- **Unggahan:** Anda mengendalikan kapan aplikasi aktif dan merekam.
- **Penghapusan:** pengguna dengan akses ke ID Room dapat menghapus klip melalui situs web VolleyCam. Anda juga dapat meminta penghapusan dengan menghubungi dukungan.
- **Pelaporan:** Anda dapat melaporkan konten tidak pantas melalui situs web.

### Cara menghapus video yang diunggah
1. Buka `volleycam.com` dan pilih room melalui menu samping “Room” (diperlukan kode 6 digit yang benar).
2. Buka event yang diinginkan.
3. Klik ikon tempat sampah di header event dan konfirmasi penghapusan.
