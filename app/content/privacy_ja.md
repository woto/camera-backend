# VolleyCam プライバシーポリシー

**最終更新日:** 2025年12月31日

## 1. 概要
VolleyCam は Android アプリと `volleycam.com` の VolleyCam ウェブサイトで構成されます。アプリは「ドライブレコーダー」型のバッファ機構でバレーボールの試合を録画し、ウェブサイトでは録画の閲覧と管理ができます。ユーザーは 6 桁のコードで特定の「ルーム」に参加し、クリップを試合セッションに紐づけます。

## 2. 収集する情報

### 2.1. 動画・音声データ
- **収集内容:** アプリはデバイスのカメラとマイクにアクセスし、バレーボールの試合の映像と音声を録音します。
- **利用方法:** アプリは映像をメモリ内で継続的にバッファします。「トリガー」イベント（ユーザー操作またはサーバー信号）発生時に、該当区間（映像・音声）を保存し、当社サーバー（`volleycam.com`）へアップロードします。
- **バックグラウンド利用:** 長時間の試合（通常 3 時間）の間、バッテリー節約のため画面オフでも録画を継続します。

### 2.2. ルーム識別子
- **収集内容:** ユーザーが任意に作成する 6 桁のルーム ID。
- **利用方法:** アップロードされたクリップを特定の試合セッションに関連付け、ウェブサイト上のアクセスを制御するために使用します。

### 2.3. ウェブサイト利用データ
- **収集内容:** IP アドレス、ブラウザ種別、閲覧ページなどの標準的なウェブログデータ。ウェブサイトはログイン状態の維持、言語設定の記憶、現在のルーム選択の保持のために Cookie を使用します。
- **利用方法:** ウェブサイトの運用、録画へのアクセス保護、必要なページや機能の提供のために使用します。

## 3. データの共有と移転
- **サーバーへのアップロード:** 記録されたクリップは当社の安全なサーバー `volleycam.com` にアップロードされます。
- **暗号化:** すべてのデータ転送は標準的な HTTPS/WSS プロトコルで暗号化されます。
- **公開範囲:**
    - ルーム ID に紐づくクリップは、有効な 6 桁コードを持つ人であれば誰でもアクセスできます。
    - **重要:** クリップが「公開」またはアップロードされた後は、正しいリンクまたはルーム ID を持つインターネット上の任意のユーザーが、ウェブサイト経由で閲覧できる可能性があります。私的または機微な場面の録画には本サービスを使用しないでください。

## 4. ユーザーの権利と管理
- **アップロード:** アプリがいつ動作し録画するかはユーザーが管理できます。
- **削除:** ルーム ID にアクセスできるユーザーは、そのルームに関連するクリップを管理（公開・削除）できます。
