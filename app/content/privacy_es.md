# Política de privacidad de VolleyCam

**Última actualización:** 31 de diciembre de 2025.

## 1. Visión general
VolleyCam incluye la aplicación para Android y el sitio web de VolleyCam en `volleycam.com`. La app graba partidos de voleibol con un mecanismo de búfer tipo “dashcam”, y el sitio web permite ver y gestionar las grabaciones. Los usuarios se unen a una “sala” mediante un código de 6 dígitos para asociar los clips a una sesión de juego.

## 2. Información que recopilamos

### 2.1. Datos de video y audio
- **Qué recopilamos:** La app accede a la cámara y el micrófono del dispositivo para grabar video y audio de partidos de voleibol.
- **Cómo se usa:** La app mantiene un búfer continuo en memoria. Solo cuando ocurre un evento de “disparo” (iniciado por usted o por una señal del servidor), el segmento relevante (video y audio) se guarda de forma permanente y se sube a nuestros servidores (`volleycam.com`).
- **Uso en segundo plano:** La app continúa grabando con la pantalla apagada para ahorrar batería durante partidos largos (normalmente 3 horas).

### 2.2. Identificación de la sala
- **Qué recopilamos:** Un ID de sala de 6 dígitos creado libremente por los usuarios para su sesión de juego.
- **Cómo se usa:** Para asociar clips subidos a una sesión de juego específica y controlar el acceso en el sitio web.

### 2.3. Datos de uso del sitio web
- **Qué recopilamos:** Datos estándar de registros web como dirección IP, tipo de navegador y páginas visitadas. El sitio web también usa cookies para mantener la sesión iniciada, recordar su idioma y conservar la sala seleccionada.
- **Cómo se usa:** Para operar el sitio web, proteger el acceso a las grabaciones y ofrecer las páginas y funciones solicitadas.

## 3. Compartición y transferencia de datos
- **Subida al servidor:** Los clips grabados se suben a nuestro servidor seguro `volleycam.com`.
- **Cifrado:** Toda la transferencia de datos está cifrada con protocolos estándar HTTPS/WSS.
- **Visibilidad pública:**
    - Los clips asociados a un ID de sala son accesibles para cualquiera que tenga ese código válido de 6 dígitos.
    - **Importante:** Una vez que un clip se “publica” o se sube, puede ser accesible públicamente para cualquier usuario en internet que tenga el enlace correcto o el ID de sala a través del sitio web. No use este servicio para grabar momentos privados o sensibles.

## 4. Derechos y control del usuario
- **Subida:** Usted controla cuándo la app está activa y grabando.
- **Eliminación:** Los usuarios con acceso al ID de sala pueden gestionar (publicar o eliminar) los clips asociados a esa sala.
